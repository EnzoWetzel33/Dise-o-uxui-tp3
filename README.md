## Descripción del Trabajo
Este repositorio contiene la resolución de los 20 ejercicios correspondientes al TP3 de HTML y CSS.
Cada actividad se encuentra organizada en su carpeta individual (`ej01` a `ej20`), incluyendo su maquetado HTML y su correspondiente hoja de estilos CSS.

---

## Estructura de Bloques
* **Bloque 1 - Nivel Básico (Ejercicios 1 al 7):** Estructura fundamental HTML5, listas, tablas, formularios simples, selectores CSS y Modelo de Caja (Box Model).
* **Bloque 2 - Nivel Intermedio (Ejercicios 8 al 14):** Layouts con Flexbox y CSS Grid, pseudo-clases, posicionamiento (`fixed`, `relative`, `absolute`), transiciones y Variables CSS (Modo Oscuro).
* **Bloque 3 - Nivel Medio/Avanzado (Ejercicios 15 al 20):** Diseños responsivos (Media Queries Desktop-First), animaciones `@keyframes`, menú hamburguesa sin JS, galería Mosaico (Masonry), formulario multi-paso y Landing Page integradora.

---

## Criterios y Decisiones de Diseño
* **Semántica:** Uso estricto de etiquetas semánticas de HTML5 (`<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`).
* **Responsividad:** Implementación de Flexbox, CSS Grid y Media Queries para garantizar una correcta visualización en distintas pantallas.
* **Estilo:** Código limpio, mantenible y modular, utilizando variables CSS globales para colores y espaciados.
